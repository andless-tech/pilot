# LCD 页面与弹窗

需要配套新版显示程序。旧固件不提供此能力，SDK 不修改已有系统页面，也不会自行升级设备。

## 支持内容

`<pilot/ui.h>` 提供文字、可编辑数值、进度条、开关和按钮。普通页面注册后出现在设备的“诊断菜单 → 扩展应用”；弹窗通过 `pilot_ui_show()` 显示。结构注册一次，之后只更新值。首版不支持任意绘图、视频、嵌套布局、运行脚本或动态增删控件；需要调整结构时移除旧页面、重新注册。

标题、控件名称最多 47 字节，文本最多 127 字节，均为 UTF-8。设备扩展字体包含 ASCII 和 GB2312 常用字符，不覆盖全部 Unicode 或 emoji。长内容显示省略号，建议标签不超过 10 个汉字、数值说明不超过 8 个汉字。

数值必须有限，绝对值不超过 `1e12`，且位于声明范围内；可编辑数值的步长必须大于零。开关固定使用 0/1、最小值 0、最大值 1。

## 最小用法

```c
#include <pilot/ui.h>

pilot_ui *ui;
pilot_ui_page page;
pilot_ui_control controls[] = {
    { .id = 1, .kind = PILOT_UI_NUMBER, .label = "目标温度",
      .text = "C", .value = 35, .minimum = 0, .maximum = 100,
      .step = 1, .enabled = true }
};
pilot_ui_page_options options = {
    .title = "我的应用", .controls = controls, .count = 1, .update_hz = 10
};
/* 检查每个函数的返回值；READY 事件表示页面已被设备接受。 */
pilot_ui_open(on_event, NULL, &ui);
pilot_ui_register(ui, &options, &page);
pilot_ui_set_value(ui, page, 1, 36);
pilot_ui_poll(ui);
```

完整可编译示例见 `examples/lcd/main.c`。示例每 20 ms 更新一次进度，实际显示更新受限频控制；按钮打开 5 秒提示弹窗，不操作通道、音频或风扇。

```sh
make
make -C examples/lcd
# 动态链接版本
make -C examples/lcd PILOT_LINK=shared OUTPUT=pilot-lcd-shared
```

## 更新与资源

- 每个 UI 实例必须由同一线程使用。业务循环至少每 100 ms 调用 `pilot_ui_poll()`，推荐 20 ms。回调在此函数内执行，不应等待网络、磁盘或耗时计算；慢任务交给业务工作线程，其结果回到 UI 所属线程再确认。
- setter 只更新本地有界状态；重复写相同属性只保留最后值。无每控件线程，无无限消息队列。每个实例最多一个请求在途，超时 1.5 秒。
- 默认前台 10 Hz，可设 1～20 Hz；后台服务最多接受 1 Hz。后台切换到前台的更新周期最迟约 1 秒恢复；隐藏页面不绘制。LCD 的实际刷新还受既有主循环与显示驱动限制。
- 客户端请求预算 16 KiB/s；设备按操作系统 UID 共用 16 KiB/s、全局 32 KiB/s 的载荷预算，允许一个预算窗口的突发。设备对注册/显示弹窗额外限制为平均 2 次/s、突发 8 次。
- 每个 SDK 实例及每个 UID 最多 4 页，设备总计最多 8 页，每页最多 32 控件。同 UID 下的多个进程共享配额，不能靠重新连接重置配额。当前它不是完整应用沙箱，不能代替 CPU/内存隔离。
- `begin → setter → commit` 可以原子提交一批变化。每批至多 64 个属性、4 KiB；过大返回 `PILOT_UI_BUSY`，草稿仍保留，可缩小或 `cancel`。SDK 不拆分批次，原子性指页面状态而非屏幕物理传输。
- 不在批次内的 setter 也会合并；待发送变化超限时返回 `PILOT_UI_BUSY`，本次修改不生效。请检查返回值，稍后重试。

## 用户操作

上下键选择；数字项按中键进入编辑，上下调节，再按中键发出操作请求。后台遥测不会覆盖正在编辑的草稿。开关/按钮直接发出 `PILOT_UI_ACTION`，由应用决定是否执行，之后调用 `pilot_ui_complete()`；成功结果以 `PILOT_UI_RESULT` 返回。示例的确认方式仅适用于立即完成的操作。

每页只允许一个待确认操作，5 秒未确认自动失效。操作队列有界：客户端最多 16 条命令，设备最多 32 条事件；满时明确返回忙，不把操作与状态合并。动作 ID 只在当前连接会话有效，旧确认被拒绝。连接中断时不能判断业务动作是否已执行，应用应自行实现业务幂等，SDK 不自动重放。

## 弹窗与恢复

- `dialog_timeout_ms` 为 1000～30000；0 表示普通菜单页。普通页面不能通过 `show()` 抢占屏幕。
- 全设备只显示一个应用弹窗。电池严重告警、启动检查、激活流程、网络诊断弹窗和系统 OTA 提示优先；应用弹窗在这些期间隐藏，超时仍计时。重复 show 不延长超时。
- 长按中键取消数字编辑、关闭弹窗或退出页面，应用不能屏蔽。退出菜单页并不移除注册。
- 每秒一次心跳，6 秒不再 poll 时页面与焦点释放；进程退出后按连接生命周期清理。所有状态仅存在内存，不写 Flash。
- 显示服务/连接恢复后自动重新注册定义与最新已提交值，收到新的 READY；旧弹窗请求与旧操作不会重放。RESET 表示本次会话失效。定义恢复不是持久化，应用进程退出后需重新注册。
- `pilot_ui_open()` 是连接初始化，可能等待本机服务连接；后续 `poll()` 的正常收发非阻塞。断线重连会重新执行连接初始化，不应在实时控制线程调用。
