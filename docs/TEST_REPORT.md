## 复现

在源码工程中：

```sh
make TARGET=host test
make TARGET=host SANITIZE=1 test
make verify
make package
python3 scripts/verify_bundle.py dist/pilot-0.2.0-arm-sdk.tar.gz
```

包验证会检查不含私有实现/协议文件，并在临时目录使用包内工具链分别编译静态和动态示例，检查静态应用不依赖 libpilot.so、动态应用依赖 libpilot.so.1。测试只终止自己创建的临时总线，不操作开发板或主机系统总线。

## 限制

- 未上传或执行开发板程序，未验证真实传感器数据、权限、配置持久化或运行负载。
- 模拟服务只验证客户端通信及数据转换，不替代板端业务验证。
- 静态 Pilot 仍依赖板端已有基础动态库，不是全静态可执行文件。
- 封装不提供协议保密、应用沙箱或安全隔离，也不会改变已经公开的仓库历史。
