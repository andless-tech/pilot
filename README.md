# Pilot 开发板 SDK

Pilot 为 Andless 开发板应用提供统一的 C/C++ 接口，便于读取设备状态、使用传感器和控制板载功能。

当前版本：**0.3.0**（本地开发版）。

## 提供的能力

| 分类 | 支持能力 |
| --- | --- |
| 传感器 | 读取 IMU 三轴加速度、角速度和磁力计数据 |
| 定位 | 查询 GPS 状态、定位信息和基站定位结果 |
| 设备状态 | 读取设备遥测、诊断信息和自检结果，触发重新自检 |
| 通道控制 | 读取控制通道、设置通道输出、查询输出状态及受控调试 |
| 音频 | 读取和设置麦克风、扬声器音量，获取音频频谱 |
| 相机 | 获取当前相机预览画面及媒体运行状态 |
| 电池 | 查询和设置电池类型、串数及相关配置 |
| ADC 校准 | 读取电压采样、应用校准及恢复默认校准 |
| 风扇 | 查询风扇状态，设置自动温控、手动档位和温度曲线 |
| LCD 扩展 | 注册菜单页和限时弹窗，显示文字、数值、进度条、开关和操作按钮；批量更新内容并接收操作事件 |
| 应用部署 | USB 上传单个不超过 1 MiB 的程序，覆盖安装、低优先级开机运行，查询状态及最近 1 KiB 日志 |
| 连接与网络 | 查询中转与点对点连接状态、传输统计、网络诊断，请求重连及设置本次启动的网络恢复策略 |

具体可用能力取决于设备固件、硬件配置及应用权限；现有设备保护机制保持生效。

## 状态通知

支持 IMU、磁力计、通道、连接、网络、自检和基站信息共七类状态更新通知。
